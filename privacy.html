隐私说明

说明日期：2026-10-24 · 适用于本机个人通知组件及本静态说明站

处理的数据与目的

组件处理已验证的邮箱地址、Google 账户标识、授权权限和 OAuth 凭据，用于确认固定账户、维护已获准的连接并发送通知。首次身份核验使用 openid 与 email；发信使用 gmail.send。组件不请求读取收件箱、邮件正文或联系人。

邮件包括既有本机维护任务的状态与失败通知，以及学习晚间提醒和周复盘结果。所需摘要由本地授权流程生成；组件按既定范围向本人固定 Gmail 邮箱发送，不从邮箱收集材料制作摘要。

本机保存与保护

OAuth 客户端凭据与刷新令牌使用 Windows DPAPI 加密保存在本人电脑，并由本机访问权限限制读取；短期访问令牌只保留在运行内存。本机管理员仍具有管理这台电脑的权限。

凭据不写入公开网页、笔记库、源码、普通运行日志或分析工件。排障回执保留必要的运行时间、状态、关联标识、错误类别和服务端受理标识；本地通知流程按其已有授权保存待发送消息和回执。

数据传输与第三方

授权、身份核验和续期需要与 Google 服务通信。获准发送时，邮件内容经 HTTPS 提交给 Google，由 Google 处理投递；相关处理适用 Google 隐私政策。

本组件不出售 Google 用户数据，不将其用于广告、用户画像或通用人工智能模型训练，也不向其他第三方主动共享 OAuth 凭据。

本应用对通过 Google API 获取的信息的使用和向其他应用的传输遵守 Google API 服务用户数据政策，包括其 Limited Use 要求。

本站公开哪些内容

本站只公开这三页应用、隐私和使用说明，不公开本人邮箱地址、本机路径、账户标识、客户端标识、令牌或其他凭据，也不上传 Vault 文件、课程正文、学习记录、通知消息和运行数据。

本站为不含 JavaScript、分析脚本、广告或外部资源加载的静态页面。若经本人确认使用 GitHub Pages 托管，GitHub 可能为提供服务和安全目的记录访问者 IP 等访问数据，具体适用 GitHub 隐私声明。点击外部政策链接后，目标网站按其自身政策处理访问。

保留、停用与撤销

本机凭据在该个人连接使用期间保留。本人可前往 Google 账户的第三方连接管理撤销授权；Google 侧撤销与本机组件停用是分别执行的动作。

清除本地加密凭据需要本人明确操作。本组件没有公开的自助删除入口，也不会在授权失效后自动重新授权。已经投递的邮件由相应 Google 账户管理，不会因撤销授权自动删除。

当前接入阶段

当前正在接入与验收。授予 OAuth 权限本身不会替代通知启用、测试发信和实际收信的确认。隐私或停用事项由账户持有者通过本机维护流程处理，本站不收集咨询表单或公众注册资料。
